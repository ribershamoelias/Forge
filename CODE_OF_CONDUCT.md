# Code of Conduct

All contributors and users of this project are expected to adhere to the following principles:

- Be respectful and inclusive.
- No harassment, discrimination, or abusive language.
- Value constructive feedback and collaboration.
- Respect the ecosystem and the work of others.

Violations may result in removal from the project and revocation of rights under the license.
