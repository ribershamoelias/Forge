# Contributing to Forge

Thank you for your interest in contributing!

## How to Contribute

- Fork the repository and create your branch from `main`.
- Document your changes clearly.
- Add your contributor record in `/Contributors/` (see LICENSE for format).
- Ensure all code is safe, idempotent, and well-documented.
- Submit a pull request with a clear description.

## Code Style

- Use TypeScript (strict mode recommended).
- Follow modular and clean architecture.
- Write clear, user-focused error messages.
- Prefer functional, testable code.

## Reporting Issues

- Use GitHub Issues for bugs, feature requests, and feedback.
- Be specific and provide reproduction steps if possible.
